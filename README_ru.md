# Darwaza

Локальный SSH/SFTP-клиент для Linux, Windows и macOS: менеджер хостов, терминал с вкладками и
панелями, сниппеты, проброс портов, экран SFTP на две панели и необязательный канал
для ИИ-помощника, где **каждое изменение вы подтверждаете сами**.

Всё работает **у вас на компьютере, без аккаунта и без сети**. Аккаунт и синхронизация
между устройствами — по желанию; сервер не может прочитать ваши данные: они шифруются
на устройстве ключом из мастер-пароля. Это принцип, а не недоработка: забытый пароль
не восстановить.

Сборки (`.deb`, `.rpm`, AppImage) — на странице
[Releases](https://github.com/ikhasanmusaev/darwaza/releases). Для Arch/Manjaro:
`cd packaging/arch && makepkg -si`.

### Windows

Установщик `Darwaza_<версия>_x64-setup.exe` — на той же странице. Он **не подписан**,
поэтому SmartScreen покажет «Windows защитил ваш компьютер»: нажмите
**Подробнее → Выполнить в любом случае**. Сверить файл можно с `SHA256SUMS` из релиза.

Данные (хосты, настройки, записи сессий) лежат в `%APPDATA%\darwaza\darwaza\data`,
токен доступа ИИ-помощника — в `%LOCALAPPDATA%\darwaza\darwaza\data`. Удаление
приложения их **не стирает**, поэтому после переустановки хосты на месте. Для полного
удаления сотрите обе папки вручную после деинсталляции. Пароли и
passphrase хранятся в «Диспетчере учётных данных» Windows (записи `darwaza`) —
удалите их там, если нужно.

### macOS

Файл `Darwaza_<версия>_universal.dmg` — на той же странице. Один файл работает и на
Apple Silicon, и на Intel. Он подписан сертификатом Developer ID и заверен Apple,
поэтому открывается без предупреждений: откройте `.dmg` и перетащите Darwaza в
«Программы». Пароли и passphrase хранятся в связке ключей macOS.

## SFTP пока неудобный

Передавать файлы можно, но удобным это ещё не назвать, и мы это знаем. С 0.1.2
приложение спрашивает, что делать с занятым именем, и умеет выбирать несколько
файлов сразу. В следующих выпусках:

- удаление папки вместе с содержимым, после подтверждения;
- строка пути, которую можно править, и сортировка по имени, размеру и дате;
- смена прав (chmod);
- правка файла сервера в своём редакторе;
- панель файлов идёт за текущей папкой терминала;
- переподключение после обрыва и закладки папок;
- скорость передачи и оставшееся время.

Если что-то мешает, откройте issue: так мы поймём, что делать первым.

## Сборка из исходников

Нужны Rust (stable), Node.js 22, pnpm и системные библиотеки Tauri 2
(WebKitGTK 4.1, libsoup 3, librsvg, patchelf).

```bash
pnpm install
pnpm tauri dev      # разработка
pnpm tauri build    # настоящая сборка (.deb, .rpm, AppImage)
```

Ставить и раздавать нужно только то, что собрано `pnpm tauri build`: обычный
`cargo build --release` ищет интерфейс на `localhost:1420` и даёт белый экран.

Проверки: `pnpm lint`, `pnpm exec vue-tsc --noEmit`, `python3 scripts/check-locales.py`,
`pnpm exec playwright test`, `cd src-tauri && cargo test --lib`.

## Что клиент отправляет по сети

В фоне — ничего. Соединение открывается, только когда вы подключаетесь к своим
серверам (SSH, SFTP, проброс портов; Ctrl+V с одной лишь картинкой в буфере передаёт её на этот сервер по тому же соединению), список хостов проверяет доступность сохранённых
хостов (только TCP-порт), нажали «Проверить обновления» (`darwaza.uz/updates`, файл
проверяется подписью), вошли в аккаунт (`api.darwaza.uz` или указанный вами сервер)
либо сами отправили отчёт о сбое на указанный вами адрес. Таблица с путями к коду — в
английском [README.md](README.md). Канал ИИ-помощника — локальный сокет с токеном, а не
сетевой порт.
