# Security policy

> **Draft.** The reporting address and response times below are placeholders until the
> maintainer confirms them.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Write privately to:

**hm.musaev@gmail.com**

Include what you found, how to reproduce it, the version (*Settings → About*) and, if you
can, the impact. You do not need to have a fix.

## What to expect
- An acknowledgement within **7 days**.
- A fix or a clear decision within **30 days** for critical issues, and credit in the
  release notes if you want it.
- Please give us reasonable time to release a fix before you publish details.

## Scope
In scope: this repository — the desktop client, the local channel to the AI assistant
(`darwaza-mcp`), how secrets are stored, the confirmation of assistant plans, updates and
their signature check.
Out of scope: the Darwaza account server and website (they are not in this repository);
problems that need physical access to an unlocked computer; issues in third-party servers
you connect to.

## Supported versions
Only the latest release receives security fixes.
